# Как запустить бота — пошагово

Инструкция рассчитана на то, что ты никогда этого не делал.
Все команды можно копировать целиком.

---

## Шаг 0. Включи VPN

**Это обязательный шаг, а не совет.** В России `api.telegram.org` блокируется
на уровне TCP: бот запустится без единой ошибки и просто будет молчать,
потому что не сможет соединиться с Telegram.

Проверка одной командой в PowerShell:

```powershell
curl.exe -s -o NUL -w "%{http_code}" --max-time 15 https://api.telegram.org
```

- `302` или `401` — всё хорошо, продолжай.
- `000` — соединения нет. Включи VPN или пропиши `PROXY_URL` в `.env` (шаг 3).

## Шаг 1. Создай бота у @BotFather

1. Открой Telegram, найди в поиске `@BotFather`
   или перейди по ссылке: https://t.me/BotFather
2. Нажми кнопку **Start** внизу.
3. Отправь ему сообщение:

   ```
   /newbot
   ```

4. Он спросит **имя бота** — то, что увидят люди.
   Пиши по-русски, можно с пробелами. Например:

   ```
   Приём заявок
   ```

5. Потом спросит **username** — это адрес бота, по нему его находят.
   Здесь только латиница, цифры и подчёркивание, и **обязательно на конце `bot`**:

   ```
   my_zayavki_bot
   ```

   Если ник занят, BotFather попросит придумать другой. Это нормально,
   просто добавь цифры: `my_zayavki_2_bot`.

6. Он ответит примерно так:

   ```
   Done! Congratulations on your new bot. You will find it at t.me/my_zayavki_bot.
   ...
   Use this token to access the HTTP API:
   1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```

**Вот эта длинная строка с двоеточием — и есть токен.** Скопируй её целиком,
вместе с цифрами до двоеточия и буквами после.

> ⚠️ **Кто знает токен — тот управляет ботом.** Не отправляй его в чаты,
> не показывай на стримах, не выкладывай на GitHub. Файл `.env` уже добавлен
> в `.gitignore`, поэтому случайно в репозиторий он не попадёт.

## Шаг 2. Узнай свой ID

Без этого заявки не будут приходить тебе в личку.

**Способ 1 — самый простой, ничего искать не надо.** Бот сам скажет тебе ID,
пока не настроен: найди своего бота и нажми у него **Start**. Он ответит:

```
⚠️ Бот ещё не настроен.

Ваш ID: 123456789

Скопируйте это число в файл .env в строку ADMIN_IDS
и перезапустите бота.
```

Число и есть твой ID. Как только впишешь его в `.env` (шаг 3), подсказка
больше не появится.

**Способ 2, если бот ещё не запущен.** Найди в Telegram `@userinfobot`
(https://t.me/userinfobot), нажми **Start**, он ответит:

```
Id: 123456789
First: Orion
```

> ⚠️ **Важный момент, на котором спотыкаются все:** найди своего нового бота
> и **нажми у него Start**. Пока пользователь не запустил бота, Telegram
> запрещает боту писать ему первым. Если пропустить — заявки будут
> сохраняться в базу, но уведомления не придут.

## Шаг 3. Заполни файл .env

В папке с ботом лежит файл-образец `.env.example`. Работает не он,
а файл с именем **`.env`** — без `.example` на конце.

Открой PowerShell и выполни:

```powershell
cd C:\Users\Orion\Downloads\telegram-bot-template
Copy-Item .env.example .env
notepad .env
```

Откроется Блокнот. Впиши свои значения:

```
BOT_TOKEN=1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
ADMIN_IDS=123456789
DB_PATH=bot.db
PROXY_URL=
```

Что здесь что:

| Строка | Что вписать |
| --- | --- |
| `BOT_TOKEN` | токен из шага 1, целиком |
| `ADMIN_IDS` | твой ID из шага 2. Несколько админов — через запятую без пробелов |
| `DB_PATH` | оставь как есть, это файл базы данных |
| `PROXY_URL` | оставь пустым, если VPN включён глобально. Иначе — адрес прокси |

Сохрани: **Ctrl + S**. Закрой Блокнот.

Проверь, что получилось:

```powershell
Get-Content .env
```

Если видишь свои токен и ID — всё верно.

## Шаг 4. Запусти бота

```powershell
cd C:\Users\Orion\Downloads\telegram-bot-template
.\.venv\Scripts\python.exe bot.py
```

Виртуальное окружение `.venv` и все зависимости уже установлены, заново
ставить ничего не нужно.

Если всё хорошо, в консоли появится:

```
2026-10-13 12:00:00 INFO Бот запущен. Администраторы: [123456789]
```

> **Окно консоли не закрывай.** Пока оно открыто — бот работает.
> Закрыл — бот выключился. Чтобы остановить, нажми **Ctrl + C**.

## Шаг 5. Проверь, что всё работает

1. Открой своего бота по адресу из шага 1: `https://t.me/имя_бота`
2. Нажми **Start**. Должно прийти приветствие и 4 кнопки внизу.
3. Нажми **«Услуги и цены»** → выбери любую услугу → **«Оставить заявку»**.
4. Пройди три шага: имя → контакт → комментарий (можно отправить `-`).
5. Нажми **«Отправить»**.
6. **Заявка должна прийти тебе в личку** отдельным сообщением.
7. Отправь боту команду `/admin` — откроется админ-панель.
   Нажми «Статистика» — там будет твоя заявка.

Если заявка пришла — бот полностью рабочий, можно сдавать клиенту.

## Шаг 6. Поменяй тексты под заказчика

Открой `config.py` Блокнотом или в VS Code. Меняется только он:

- `COMPANY_NAME` — название компании
- `GREETING` — первое сообщение
- `CONTACTS` — телефон, адрес, сайт
- `SERVICES` — список услуг: название, цена, описание

После правок перезапусти бота: **Ctrl + C**, потом снова `bot.py`.

## Если что-то не работает

| Что видишь | В чём причина | Что делать |
| --- | --- | --- |
| `BOT_TOKEN не задан` | нет файла `.env` или он пустой | вернись к шагу 3 |
| Бот запустился, но молчит и не отвечает | Telegram API заблокирован провайдером | включи VPN, проверь шагом 0 |
| `Unauthorized` | токен скопирован не полностью | скопируй токен из BotFather заново |
| Заявки идут, а уведомления нет | не нажал Start у своего бота или неверный `ADMIN_IDS` | шаг 2 |
| `Conflict: terminated by other getUpdates` | запущено два бота одновременно | закрой лишние окна консоли |
| `ModuleNotFoundError: aiogram` | запускаешь системным Python, а не из `.venv` | используй путь `.\.venv\Scripts\python.exe` |

## Бонус: оформить бота под клиента

Всё это делается в чате с `@BotFather`, командами:

| Команда | Что делает |
| --- | --- |
| `/mybots` | список твоих ботов, управление |
| `/setname` | имя бота |
| `/setdescription` | описание — его видно до нажатия Start |
| `/setabouttext` | короткая строка в профиле бота |
| `/setuserpic` | аватарка бота |
| `/setcommands` | список команд в меню |

Заказчику важно видеть нормальную аватарку и описание — иначе бот выглядит
недоделанным, хотя код работает.
